Astra 1.0.0 — серверный плагин Paper 1.21.11

ЧТО ЭТО:
astra-1.0.0.jar — готовый к установке файл плагина (в корне этого архива).

КАК УСТАНОВИТЬ:
1. Скачайте этот ZIP и распакуйте его (правой кнопкой -> "Извлечь всё").
2. Возьмите файл astra-1.0.0.jar.
3. Скопируйте его в папку plugins на вашем сервере Paper 1.21.11.
4. Запустите/перезапустите сервер. Готово.

ЕСЛИ ХОТИТЕ ВЫЛОЖИТЬ НА GITHUB:
1. Откройте ваш репозиторий на github.com в браузере.
2. Нажмите кнопку "Add file" -> "Upload files" (находятся над списком файлов).
3. Перетащите туда файл astra-1.0.0.jar.
4. Нажмите "Commit changes". Файл появится в главном списке репозитория,
   и любой сможет скачать его кнопкой Download.

КОМАНДЫ ПЛАГИНА: /astra menu | status | stop <id> | stopall | reload |
set <игрок> | cast <способность> | scene list/start/stop/edit
Полное описание — в README.md внутри архива.
